# Legacy Scripts Archive

This directory contains historical, one-off automation scripts developed for specific coursework iterations (such as Computer Networks, Distributed Web Mining, Cryptography & System Security).

## Context & Purpose
- **Archival Only:** These scripts were hardcoded with course-specific IDs, personal student identifiers, and custom manual flows.
- **Superseded by Modular Suite:** All submission, report generation, and verification workflows have been refactored into the universal `classroom/` library and `classroom_agent.py` CLI.
- **Exclusion:** This directory is ignored from distribution to ensure clean, generic student setups without private roll numbers or subject lock-in.
